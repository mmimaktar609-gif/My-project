Hriday Bot Panel
A lightweight mobile-friendly Node.js bot management panel.
Features
Dashboard statistics
Create bot projects
Start / Stop / Restart Node.js bots
Process PID and crash counters
Console log viewer
File upload
JSON persistence
Render-friendly PORT support
Run locally
npm install
npm start
Open http://localhost:3000
Render deployment
Create a new Web Service.
Connect this repository/project.
Build Command: npm install
Start Command: npm start
Node 18+ recommended.
Important
This MVP intentionally does not implement Facebook login/cookie harvesting. If you later add credentials for a bot, store secrets securely and never print them in logs.
