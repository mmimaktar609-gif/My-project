💠 HRIDOY BOT PANEL V2
Mobile-friendly Node.js bot management panel.
Features
Dashboard statistics
Create Bot
Start / Stop / Restart
Console logs
Delete Bot
Automatic status refresh
Local JSON metadata
No Facebook cookies or login credentials stored
Run
npm install
npm start
Open: http://localhost:3000
Deploy
Use a Node.js Web Service. Build command: npm install
Start command: npm start
Node 18+ recommended.
Important
This MVP runs bot processes on the same server. Only deploy it on a server you control and protect any production admin/login layer before exposing it publicly.
